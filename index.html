About me

I am a Computer Science student at the Georgia Institute of Technology, currently taking CS 2340, Objects and Design. This portfolio showcases the GT Movies Store, the web application I designed and developed for that course.

What draws me to software is the part where separate pieces have to agree with each other. A model definition, a database table, a URL route, and a template all have to line up before a single page loads, and when one of them is wrong the error usually shows up somewhere else entirely. This project was my first time carrying an application all the way from an empty project folder to a live site on the public internet, and most of what stuck with me came from the parts that did not work on the first attempt.

Outside of coursework I watch a lot of movies, which made a movie store a more entertaining thing to build than it might sound. I am interested in backend development and in the design decisions that keep an application understandable as it grows.

What I worked with

Python and Django 5

Models, views, URL routing, templates, sessions, forms, and the built-in authentication system.

Databases

SQLite and MySQL through the Django ORM, with migrations and the phpMyAdmin interface via XAMPP.

Frontend

HTML, the Django template language, CSS, and Bootstrap for a responsive layout.

Tools and deployment

Git and GitHub for version control, and PythonAnywhere for hosting the live application.

The project

The GT Movies Store is a Django web application where visitors can browse and search a movie catalog, create an account, write and manage reviews, build a shopping cart, and place orders. Administrators manage users, movies, reviews, and orders through the Django admin panel.
